# Diyar-e-Libas — Website Base

A starter visual foundation for a Pakistani men's unstitched-fabric brand.

## Files
- `index.html` — one-page homepage draft
- `css/style.css` — responsive styling
- `js/main.js` — mobile navigation and footer year
- `assets/products/` — add approved product photos here

## Preview locally
Open `index.html` in a browser, or use VS Code's Live Server extension.

## Deploy to GitHub + Vercel
1. Create a GitHub repository.
2. Upload all files while preserving the folder structure.
3. Import the repository into Vercel.
4. Select `Other` as the framework preset for this static HTML project.
5. Deploy and test the generated URL.

## Before launch
This is a visual base, not a complete online store. Product cards do not yet open real product pages, and checkout, database/order records, courier integration, WhatsApp support links, privacy policy, return policy, analytics and Meta Pixel are not implemented.

Replace all placeholder fabric illustrations with genuine, approved Diyar-e-Libas product photography. Confirm fabric length, composition, available colours, delivery charges and final policies before publishing. Do not publish placeholder claims or accept real customer orders until checkout and order handling are implemented and tested.
